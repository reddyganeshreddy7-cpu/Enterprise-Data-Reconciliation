# Enterprise Data Reconciliation

## Project Overview
This project demonstrates enterprise data reconciliation using Python, Pandas, SQLite, and Regular Expressions.

## Tools Used
- Python
- Pandas
- SQLite
- Jupyter Notebook

## Project Workflow
1. Read server logs
2. Extract data using Regex
3. Clean and validate the data
4. Read exchange-rate data
5. Connect to SQLite database
6. Merge datasets
7. Export final reconciled data

## Files
- Project.ipynb
- enterprise_database.db
- server_logs.txt
- daily_exchange_rates.csv
- Final_Reconciled_Data.csv
- Enterprise_Report.xlsx
